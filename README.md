# Tiinex organization profile

This repository contains the public GitHub organization profile for Tiinex and the shared artwork used by that profile.

- [`profile/README.md`](profile/README.md) — public organization landing page
- [`assets/`](assets/) — shared profile artwork
- [`assets/tiinex-system-map.png`](assets/tiinex-system-map.png) — current public system map

## Responsibility boundary

This repository is a presentation surface, not a semantic or implementation authority.

- [`Tiinex/docs`](https://github.com/Tiinex/docs) owns canonical schemas and semantic contracts.
- [`Tiinex/business`](https://github.com/Tiinex/business) owns project intent, initiatives, roles, and human gates.
- [`Tiinex/core`](https://github.com/Tiinex/core) implements shared host-neutral mechanics and Tooling.
- Individual repositories own their package, host, provider, Verse, interoperability, or runtime responsibilities.

The organization profile should stay simple and durable. Product status, release history, implementation notes, and temporary development state belong in the repositories that own them.
